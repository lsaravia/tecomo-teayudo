# ¿Te como o te ayudo?

Presentación de divulgación científica sobre redes ecológicas e interacciones entre especies, desarrollada para explicar cómo las conexiones entre los organismos estructuran los ecosistemas marinos del Canal Beagle y por qué son fundamentales para comprender su funcionamiento y conservación.

**Versión web:** https://lsaravia.github.io/tecomo-teayudo/
  
  
  
## Cómo reproducir la presentación

Instalar las dependencias necesarias y ejecutar:
  
`rmarkdown::render("Presentacion.Rmd", output_file = "index.html")`
