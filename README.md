# ¿Te como o te ayudo?

Presentación de divulgación científica sobre redes ecológicas e interacciones entre especies, para el ciclo Bitácora Fueguina.  

La charla introduce el concepto de redes ecológicas utilizando ejemplos reales de depredación, competencia, mutualismo y provisión de hábitat, mostrando cómo este enfoque ayuda a comprender problemas ecológicos y de manejo, como la recuperación de la centolla.
